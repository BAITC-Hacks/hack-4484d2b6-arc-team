## После обновления main

Сохранить локальную работу перед обновлением. Для чистой main:

```sh
git switch main
git pull --ff-only origin main
```

Для рабочей ветки участника: git fetch origin, затем git merge origin/main
после сохранения своих изменений. Не использовать force push и не удалять БД.
Перезапустить FastAPI, поскольку работающий процесс не перечитывает Python-код
автоматически. Seed идемпотентен; публикации создаются отдельно через конструктор.

Следующий этап продукта — авторизация и production-инфраструктура; демопрофили,
локальная SQLite, ручное обновление и отсутствие изменения окончательных решений
описаны как ограничения MVP, а не как готовые функции.
