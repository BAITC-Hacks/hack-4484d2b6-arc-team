# Форма отклика — участник №3

Форма подключена к API v0.4 участника №1 (`feat/backend-workflow`, проверенный
commit `380d94a`). Общая синхронизация веток ещё не выполнена. На backend v0.3
публичный каталог и отправка недоступны; интерфейс не показывает фиктивный успех.

## Сценарий

1. Открыть `/ui#catalog`, выбрать опубликованную задачу и «Подготовить отклик».
2. Выбрать роль команды и профиль из `GET /api/demo/profiles`.
3. Заполнить идею, план и сроки. Прототип и вопросы бизнесу необязательны.
4. Ввод автоматически сохраняется. Сохранение допускает неполный черновик;
   проверка показывает ошибки около полей. Рейтинг, включая 0, не закрывает форму.
5. «Отправить отклик» выполняет `POST /api/tasks/{id}/proposals` с выбранным
   `X-Demo-Team-Id`. Передаются только пять полей, внешние пробелы удаляются,
   пустая ссылка передаётся как `null`.
6. После ответа сервера появляются статус и ссылка `/ui#proposals/{proposal_id}`.
   После отправки нельзя редактировать/отзывать предложение: текущий API этого
   не предусматривает. Локальный черновик не удаляется.

Перед отправкой форма загружает собственные отклики через `GET /api/my/proposals`.
Если команда уже откликнулась, показан существующий статус вместо второй формы.
При ошибке проверки отправка блокируется, локальный ввод остаётся доступен.
Во время POST поля и выбор команды блокируются; запоздавший ответ не изменяет
другую задачу/команду. Ошибка 409 запускает проверку существующего отклика.

## Хранение и контракт

Ключ: `ai-sana:proposal-draft:v1:` + JSON-массив `[source, task_id, team_id]`.
Значение: `{version:1, source, task_id, team_id, values, updated_at}`.
Для публикаций `source=public`. Старые `demo`-черновики не удаляются
и не привязываются к реальным задачам по названию.

Выбор команды: `ai-sana:proposal-team`, общий с кабинетом. При запрете/переполнении
localStorage используется память вкладки с предупреждением: после перезагрузки
такой ввод может потеряться.

Обязательные строки: `idea`, `plan`, `timeline`; необязательные:
`prototype_url`, `questions`. До 20 000 символов, ссылки только абсолютные HTTP(S),
без встроенных логина/пароля. Повтор идентичного предложения возвращает прежнюю
запись; другое предложение той же команды на ту же задачу — `409 proposal_exists`.

Ввод отображается через textContent/value, а не HTML. Права проверяет сервер.
Демопрофили не являются авторизацией. Подробнее: [TEAM_WORKSPACE.md](TEAM_WORKSPACE.md).
