## Текущий результат: общая оболочка интерфейса

Первый шаг участника №2: Soft Retro по согласованному макету. Реализованы общие цвета, кнопки, карточки, статусы, боковая навигация, переключение демонстрационной роли и адаптация оболочки под размер окна. Все ресурсы локальные, установка зависимостей не требуется.

Конструктор пока **образец интерфейса**: описание доступно только для чтения, вопросы — статические примеры, 55/100 — иллюстрация уровня «Рабочая», подтверждение отключено. Кабинеты обозначены как будущие страницы. Каталог участника №3 показывает пять явно обозначенных демонстрационных карточек с поиском, фильтрами и сортировкой. Серверный AI-конструктор уже работает через API, но ещё не подключён к этому интерфейсу. Расчёт рейтинга и публикация пока не реализованы.

## Просмотр

Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory app
```

Открыть http://127.0.0.1:8000/templates/base.html. Для просмотра нужен HTTP-сервер, не `file://`.

При запуске FastAPI по [инструкции сервера](docs/BACKEND.md) интерфейс доступен на
http://127.0.0.1:8000/ui, каталог — http://127.0.0.1:8000/ui#catalog.

Проверка: переключить разделы боковой панели, вернуться к конструктору, раскрыть примеры вопросов, выбрать «Команда · Орбита» и обновить страницу. Выбранная роль сохраняется локально, если браузер разрешает хранилище. Названия профилей синтетические; переключатель не выполняет авторизацию и не даёт прав на сервере.

## Передача другим участникам

- `app/templates/base.html` — общая HTML-оболочка с демонстрационным содержимым. При подключении FastAPI её можно отдать через Jinja и заменить содержимое `<main>` блоками страниц. Сейчас шаблон не требует Jinja.
- `app/static/styles.css` — общие CSS-переменные и компоненты: `.button`, `.button-primary`, `.button-outline`, `.panel`, `.badge`, `.icon`, `.form-field`, `.field-control`, `.field-error`. Стили других страниц добавлять отдельными файлами. Палитра: молочный `#F8F5ED`, тёмно-синий `#172B4D`, голубой `#DCEAFF`, мятный `#DDF3E5`, жёлтый `#F9E6A4`, основная кнопка `#216BE0`.
- `app/static/icons.svg` — локальный SVG-спрайт; `favicon.svg` — знак приложения. Внешних шрифтов, библиотек и заимствований из JARVIS нет.
- `app/static/shell.js` — только навигация и демороль. Адреса `#builder`, `#catalog`, `#business`, `#proposals` действуют внутри предварительного просмотра, это не согласованный серверный роутинг.

Сервер раздаёт `app/static` по `/static` и оболочку на `/ui`; API на `/` сохранён. Контракт сервера и идентификаторы профилей описаны в docs/API.md; переключатель пока не подключён к API. Для будущего подключения переключатель выставляет `data-demo-role` на `<html>` и при выборе отправляет локальное событие `sana:demo-role-change` с `detail.role` (`business` или `team`). Это UI-намерение; идентификатор профиля и проверка прав остаются ответственностью сервера.

## Участник №3 — шаг 1: каталог

Реализованы карточки в стиле Soft Retro, поиск по названию/описанию/результату,
совместные фильтры по теме и готовности, сортировка по баллу (при равенстве — по
времени и ID), сброс, пустое состояние, ошибка загрузки с повтором и краткий предпросмотр.
Карточка с 35 баллами доступна так же, как остальные.

`app/static/catalog-demo.json` — синтетические **примеры отображения**, а не
опубликованные записи БД. Баллы заданы только для демонстрации уровней и не доказывают
работу будущей формулы. Клиент не считает рейтинг и не читает приватный `/api/tasks`.
Отклики и полная страница задачи остаются следующими шагами.

Стили изолированы в `catalog.css`, поведение — в `catalog.js`. После появления
публичного API заменить источник в `load()` и сверить согласованный формат:
`id`, `topic`, `status`, `published_at`, `published_card`, `published_rating`.
Не переключаться на фиктивные данные незаметно при ошибке реального API.

Проверка: открыть каталог, выбрать «Черновик · 0–39», открыть задачу с 35 баллами,
закрыть предпросмотр, выбрать дополнительно «Логистика» (пустой результат), сбросить
фильтры и найти «диспетчеру». Должна остаться одна задача. Без фильтров баллы идут
90, 75, 75, 55, 35. Общие тесты: `python -m pytest -q`.

Следующие шаги участника №2: действующий конструктор, серверная панель рейтинга и кабинет бизнеса после согласования API. Общий план проекта: [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md). Выбранный Soft Retro заменяет прежнее упоминание тёмной темы в историческом плане.
